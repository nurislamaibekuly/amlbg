features

The whole pipeline — artwork rotation, bloom, warp and grade — in one ES module with no dependencies.

  • Reference-matched gaussian blur

    Separable two-pass kernel with zero edge clamping, half-texel sigma quantization and half-float intermediates — numerically verified against the original.

  • Catmull-Clark pinch mesh

    Seeded control grids — 5 landscape and 5 portrait pairs — subdivided twice into a smooth warp that breathes with the music.

  • Palette extraction & grade

    Dominant and accent colours are pulled from your artwork, then drive the saturation grade, scrims and an ordered dither.

  • Audio-reactive spectrum

    Feed a four-band energy spectrum and the backdrop scales, warps and transitions with it — or run it in simulated mode.

quick start

No build step. Any static file server will do.

ES modules don’t load from file://, so serve the folder over HTTP. This page is the demo.

main.js

import MeshBackdrop from './amlbg.js';

const backdrop = new MeshBackdrop(canvas, {
  seed: 'aurora',
  cover: artwork,
  autoStart: true
});

backdrop.setCover(nextArtwork, 'ember');
backdrop.setParameters({ blurScale: 1.4 });

terminal

# from the repository root
python3 -m http.server 8000

# then open
http://127.0.0.1:8000/
